# DESIGN 规范：报告类蓝白双风格

> 在同一 `blue-white-design` 技能内提供两套独立风格：**深蓝白 / deep** 与 **浅蓝白 / light**。深蓝白不是整页暗色模式，浅蓝白也不是给旧模板换一个背景色。
> 本文为完整设计规范；技能内 `references/design-spec.md` 是同一文本的镜像。维护时先改完整规范，再同步镜像、两份轻量执行页与两份 HTML 模板，保持单一内容源与相对目录结构。
> v2 保留原风格识别，新增浅色方案；间距、字阶、圆角、阴影和对比度属于规范化调整，不冒称原成品逐像素数值或已完成用户验收。
> v3 只新增「局部玻璃层」这一层可选增强：**玻璃不改动两套风格的首屏、字色、结论与收尾签名**，正文始终留在清晰的不透明或高不透明层上。v3.1 为走查修订版，补齐状态、字阶、空态与可追溯规则。v3.2 为第二轮复审修订版：补锚点按下态、空态对齐与 live region 边界、加载态焦点、强制色彩回退与 200% 缩放口径。
> 本文不含任何设备路径、账号、仓库地址或外部链接，可直接随技能分发。

## 1. 先选一套，禁止混搭

| 维度 | 深蓝白 `deep` | 浅蓝白 `light` |
|---|---|---|
| 适用 | 重点汇报、成果总览、竞品结论、强调展示 | 长文方案、知识阅读、行动清单、维护说明 |
| 首屏 | 深蓝渐变 + 反白字 + 受保护的结论卡 | 浅蓝渐变 + 墨蓝字 + 直接排版 |
| 正文 | 白至浅蓝卡片，紧凑清晰 | 白至浅蓝卡片，长文舒展 |
| 收尾 | 深蓝渐变 + 反白节点卡 | 浅蓝至白渐变 + 墨蓝总结 |
| 装饰 | 白色圆形光晕，适度强调层次 | 右上淡蓝径向光晕，低干扰 |
| 玻璃层 | 3 个模糊层：跨首屏导航条、首屏口径条、收尾节点容器 | 1 个模糊层：跨首屏交界的浮动导航条 |
| 模板 | `assets/blue-white-report-template.html` | `assets/blue-white-light-report-template.html` |
| 页面标记 | `data-blue-white-style="deep"` | `data-blue-white-style="light"` |

- 按明确指定选用；“浅色蓝白 / 阅读型”选 light；“深蓝首屏 / 深蓝白 / 展示型”选 deep。
- 只说“蓝白”，无其他线索时沿用 deep 以兼容旧用法，并在开头说明选型；有歧义且会影响交付时只问一次。
- 选定后成套使用首屏、字色、结论、收尾和阴影。禁止浅蓝首屏保留白字、浅色报告夹入深蓝收尾、深蓝白被理解为整页深蓝。
- 玻璃层是两套各自配方内的**局部增强**，不是第三套风格，也不能跨套借用：deep 的深底玻璃卡不得搬到 light。

## 2. 共享基础：只保留必要 token

|---|---|---|
| `--ink` | `#0f2a52` | 主标题、正文，替代纯黑 |
| `--muted` | `#3b5b8f` | 辅助、日期、来源；不用旧 `#7d90ad` 做小字 |
| `--primary` | `#1d6ef5` | 强调线、图形、装饰，不默认用作浅蓝底小字 |

| `--tint-pressed` | `#c6dcfa` | 锚点类控件按下态（两套通用）；light 按钮按下态；与 hover 的 `--tint` 明确区分 |

| `--finance-red` / `--finance-green` | `#e64545` / `#1fa663` | 金融图形：红涨绿跌；须由 `.finance` 数值组件落地，不只写在文档里 |

```css
--page-bg: linear-gradient(180deg,#eef4fd 0%,#f7fafd 40%,#eef4fd 100%);
--table-bg: linear-gradient(135deg,#eaf2ff,#f5f9ff);
```

仅按内容需要出现语义色，不用多彩标签装饰；AI 标识保持蓝色。金融涨跌和完成/失败是两组语义，不凭颜色推断数值好坏。**每套模板只声明自己用到的 token**；确需预留的语义变量写入本表并在模板中标注 `/* reserved */`，不留静默未使用变量。

### 2.2 字阶（字号 / 行高 / 字重，px；成组定义，禁止临时值）

字体：`-apple-system,"PingFang SC","Hiragino Sans GB","Microsoft YaHei",sans-serif`。

| 角色 | 深蓝白 | 浅蓝白 | 变量 |
|---|---|---|---|
| 首屏标题 | `clamp(26px,3.15vw,34px)` / 1.29 / 800 | 同左 | `--type-hero` |
| 章节标题 | 24 / 36 / 800 | 同左 | `--type-h2` |
| 卡片标题 | 18 / 28 / 700 | 同左 | `--type-h3` |
| 首屏引言 | 20 / 32 / 700 | 同左 | `--type-lead` |
| 正文 | 14 / 24 / 400 | 15 / 28 / 400 | `--type-body` |
| 表格正文 | 14 / 24 / 400 | 14 / 24 / 400 | `--type-table` |
| 按钮文字 | 14 / 24 / 600 | 14 / 24 / 600 | `--type-button` |
| 章号 | 14 / 24 / 800（40px 反白方块内） | 14 / 36 / 700（文字式 `01 /`） | `--type-section-no` |
| 说明与来源 | 13 / 24 / 400 | 同左 | `--type-caption` |
| 标签 | 12 / 20 / 600 | 同左 | `--type-tag` |
| 统计数字（按需） | 40 / 48 / 800 | 同左 | `--type-stat` |

- `clamp()` 的字号两端为 26px 与 34px，行高按 1.29 连续插值（约 34px 与 44px）；中间宽度只允许连续插值，不允许另起一档字号，也不再另设手机字号档。
- 组件使用 `font:var(--type-*)` 成组引用，不再散写 `font-size` + `line-height` 对；`font-weight` 需要单独覆盖时写明是例外。
- 仅首屏标题加 1px 字距；数字、日期使用 `tabular-nums`；不使用渐变文字或降低透明度的正文。

### 2.3 间距、圆角、布局

- 间距唯一梯度：`4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 56 / 64px`。边框宽度、字体和形状尺寸不受间距梯度约束。
- 圆角只三档：`12px` 小件、`24px` 卡片/总结、`32px` 首屏；胶囊 `999px`、正圆 `50%` 是形状，不加第四档。
- 容器 `max-width:1080px`，居中；桌面外层 `32px 24px 64px`，手机 `16px 16px 40px`。
- 首屏内边距 40px，手机 24px；卡片 24px，手机 16px；网格 gap 16px。
- 章节间距：deep 56px，light 40px。说明按标题起点对齐，不用浮动补空格。
- 断点 `760px`：正文双栏转单栏，流程最多两栏；统计按空间自适应。**另设 `1024px` 中间宽度检查点**：只调整容器内边距与网格列数，不改字号；不新增第三个断点。
- 表格仅局部横向滚动，不允许整页横向滚动；滚动容器可聚焦且有可读名称。
- 方向一律用逻辑属性：`border-inline-start`、`padding-inline-start`、`text-align:start`、`inset-inline-start`；不使用 `border-left` / `padding-left` / `text-align:left` / `left`，以便未来出中英混排或 RTL 报告时不翻转。

### 2.4 玻璃层（v3 新增，两套共用 token）

方法来自《磨砂玻璃界面，层次这样做》：信息面板必须压在有色块、渐变或光晕上；**先做出能看清的半透明底，再模糊面板背后的内容**，文字另留在清晰层；背景越花越要提高底色不透明度，模糊不是越大越好；边框和轻阴影只负责分层；`backdrop-filter` 作用于背后、`filter` 作用于元素自身，不能互换；不支持时保留高不透明底色并在目标浏览器核对。示例 `color:#123047` 映射为 `--ink`，`border-radius:24px` 复用 `--radius-m`，**不新增第四档圆角或阴影**。

| 变量 | 值 | 用法 |
|---|---|---|
| `--glass-fill` | `rgb(255 255 255 / .55)` | 标准玻璃底；light 默认 |
| `--glass-fill-strong` | `rgb(255 255 255 / .72)` | 背后有渐变 / 光晕 / 双色交界时提高不透明度；deep 默认 |
| `--glass-blur` | `16px` | 固定值，不随组件放大 |
| `--glass-stroke` | `rgb(255 255 255 / .70)` | 深底上的白色高光描边，仅用于分层 |
| `--glass-stroke-soft` | `rgba(15,42,82,.12)` | 近白底描边；白描边在近白底不可见，必须换这一档 |
| `--glass-fallback` | `rgb(255 255 255 / .88)` | 无模糊支持时保留的高不透明半透底 |
| `--glass-print` | `#ffffff` | 打印用不透明底 |

```css
.glass{position:relative;background:var(--glass-fill);backdrop-filter:blur(var(--glass-blur));-webkit-backdrop-filter:blur(var(--glass-blur));border:1px solid var(--glass-stroke);border-radius:var(--radius-m);color:var(--ink);box-shadow:var(--shadow-s)}
.glass--strong{background:var(--glass-fill-strong)}
.glass--soft-stroke{border-color:var(--glass-stroke-soft)}
@supports not ((backdrop-filter:blur(1px)) or (-webkit-backdrop-filter:blur(1px))){.glass{background:var(--glass-fallback)}}
@media print{.glass{backdrop-filter:none;-webkit-backdrop-filter:none;background:var(--glass-print);border-color:var(--line);box-shadow:none;color:var(--ink)}}
@media(forced-colors:active){.glass{backdrop-filter:none;-webkit-backdrop-filter:none;border-color:CanvasText;box-shadow:none}}
```

硬规则：

- **玻璃面板内所有文字一律 `--ink`**。按深蓝渐变最亮端 + 白色光晕 + 保护层的合成计算：`.55` 底上 ink 最差 5.64:1、`.72` 底上 8.30:1；同场景下 `--muted` 仅 3.97:1、`--link` 更低，均不满足 4.5:1。light 的 `.55` 玻璃底上 ink 最低也 ≥4.5:1。玻璃内禁用 muted、link、透明白、渐变文字与低透明度小字。
- 玻璃只允许一层，不套玻璃；只承载标题 + 1~2 句短信息，不承载表格、长段落、代码、状态按钮组或六态控件。交互控件保持不透明底。
- 背后必须有可见渐变 / 光晕 / 色块交界；纯白或近纯白底不加玻璃。**唯一例外是 light 的跨首屏浮动导航条**：它作为本套的风格签名保留玻璃，但必须满足 `.55` 底、软描边、单层、跨两种底色、文字全 ink、有降级回退；不得因此把玻璃扩展到 light 的其它位置。该例外的模糊视觉收益有限，保留理由是层次签名而非折射效果，规范不再同时给出相反的禁止表述。
- 模糊只作用于面板背后，不得把文字、图标一起模糊；`backdrop-filter` 与 `-webkit-backdrop-filter` 成对书写，**不得用 `filter:blur()` 替代**——`filter` 作用于元素自身，会把面板文字一起糊掉。透明度只写在 `background` 的 alpha 上，不给整个面板加 `opacity<1`，否则文字一起变淡。
- 层叠属性不凭经验下结论：交付前须在目标浏览器实际看一次模糊与降级效果。分层用 `position:relative;z-index` 与描边/阴影完成。浏览器实测记录见附录 A，不当作跨浏览器硬规则。
- 不新增阴影档（默认 `shadow-s`，跨边界浮动条最多 `shadow-m`）、不新增圆角档；玻璃不改变 4px 间距梯度与字阶。
- **减层原则**：同一片深蓝渐变上的并列节点卡共用一个玻璃容器，内卡改不透明，不逐张叠加 `backdrop-filter`。deep 一页模糊层上限 3，light 上限 1。
- 打印、减少动效与不支持 `backdrop-filter` 时一律回退到高不透明或实底；不出现“只有透明、没有模糊”的漂浮层。
- **强制色彩模式（`forced-colors:active`）**：颜色由系统接管，玻璃必须关闭模糊、描边改用 `CanvasText`、去掉阴影；该模式不再追加渐变或半透明底回退，避免在系统实色底下空跑模糊。

## 3. A 套：深蓝白 / deep

### 3.1 签名配方

```css
--hero-gradient: linear-gradient(120deg,#0b3ea8 0%,#1d6ef5 55%,#4f9cff 100%);
--closing-gradient: linear-gradient(135deg,#0b3ea8,#1d6ef5 60%,#3f8dfd);
--card-bg: linear-gradient(160deg,#ffffff 0%,#f2f7ff 100%);
--on-strong: #ffffff;
--strong-scrim: rgba(15,42,82,.50);
--conclusion-bg: rgba(15,42,82,.32);
--shadow-s: 0 10px 30px rgba(29,110,245,.07);
--shadow-m: 0 16px 44px rgba(15,42,82,.16);
--shadow-l: 0 24px 60px rgba(29,110,245,.28);
```

- 首屏/收尾把 `--strong-scrim` 作为渐变上方、文字下方的统一保护层；圆形光晕也置于保护层下面。不能让白字直接落到 `#4f9cff` 上。
- 首屏结论用深墨蓝半透底 + 反白文字，**保持不玻璃化**：它是全页最重要的文字，不拿可读性换效果。玻璃只用于 3.3 列出的辅助信息层。
- 首屏和收尾所有说明用不透明白，不再套低对比度透明白。金色若保留仅作装饰，不承担正文。
- 白色正文卡片搭配蓝影；章节编号用深蓝底反白，或墨蓝数字直接排版；避免浅蓝渐变端的小白字。
- 推荐结构：结论 → 总览 → 关键发现 → 明细 → 风险 → 下一步 → 来源。按内容删减，不强制插入人员卡和统计。

### 3.2 边界

保留“首尾深蓝，中间白浮”节奏；不把所有章节改为深底，不叠满光晕，不用彩虹头像。原 v1 参数保留于本轮备份，不再指导新生成。

### 3.3 玻璃落点（deep）

| 位置 | 玻璃 | 说明 |
|---|---|---|
| 跨深蓝首屏与浅色正文交界的浮动章节导航条 | ✅ 模糊层 1 | 同时压在两种底色上，模糊收益最大；条内胶囊仍是白底蓝字 |
| 首屏内覆盖渐变 / 光晕的短口径条 | ✅ 模糊层 2（可选） | 只放 1 句范围或口径，不放结论 |
| 收尾深蓝区的「下一步」节点容器 | ✅ 模糊层 3 | 容器一层玻璃，3 张节点卡改不透明白底 + line 描边 |
| 结论主块、首屏标题与副标题 | ❌ | 保持反白与受保护深墨蓝半透；不玻璃化 |
| 白底正文卡片、表格、折叠区、来源、按钮六态 | ❌ | 背后近乎纯色，玻璃无收益且降低对比 |

- deep 默认 `--glass-fill-strong` + `--glass-stroke`，玻璃内文字全部 `--ink`；不使用反白字。
- **跨首屏与浅色正文交界的导航条同时压在两种底色上**：容器描边保留白 70%，它在深色侧负责分层，浅色侧不可见属已知取舍；控件识别由条内白底胶囊 + line 描边承担，因此不为 deep 额外引入 `--glass-stroke-soft`，也不把这条当成交互缺陷。
- 玻璃卡与反白结论卡不并排承担同一层结论；玻璃只承载辅助信息，避免同一深蓝区明暗互相打架。
- 可选变体：仅在明确要求“玻璃结论卡”时，把结论主块换成白玻璃 + ink 文字、标题仍反白；须重新测量合成对比度。默认不启用。

## 4. B 套：浅蓝白 / light

### 4.1 签名配方

```css
--hero-bg: linear-gradient(120deg,#deedff,#f0f7ff 65%,#ffffff);
--hero-line: #c6dcfa;
--hero-glow: radial-gradient(circle,#abcfff66,transparent 70%);
--card-bg: linear-gradient(160deg,#ffffff,#f3f8ff);
--closing-bg: linear-gradient(135deg,#e1eeff,#ffffff);
--closing-line: #bbd6fb;
--shadow-s: 0 10px 30px rgba(29,110,245,.07);
--shadow-m: 0 12px 34px rgba(29,110,245,.09);
--shadow-l: 0 20px 50px rgba(29,110,245,.086);
```

- 首屏：浅蓝至白、细蓝描边、32px 圆角、右上淡蓝径向光晕。主标题用 ink，引言20px，来源用 muted；禁止白字和毛玻璃结论。
- 导航：白底、蓝字胶囊，支持换行；仅作为真实章节锚点，不为装饰造按钮。
- 章节：推荐“01 / 标题”直接排版，无需每章蓝色实心徽章。
- 卡片：白到 `#f3f8ff` 的极淡渐变、24px 圆角、line 描边、shadow-s。长文优先单栏，比较内容才双栏。
- 提示：tint 底 + 4px primary 逻辑起始边线 + ink 正文；无需再次加重阴影。
- 层级/流程/待办：白或 tint 背景，必要时在浅层之间切换；不叠加三层以上卡片。
- 表格：table-bg 表头、细分隔、hover 浅蓝；正文用 `--type-table`（14/24）。折叠内容用原生 details/summary，保留展开提示。
- 收尾：closing-bg + closing-line + 墨蓝字；不借用深蓝白的反白行动区。
- 推荐结构：结论 → 章节导航 → 方案/对照 → 流程 → 待办 → 边界/依据。没有数据就不造统计卡。

### 4.2 来源值与规范值分开

参考页首屏 padding 38px、卡片25px、gap17px、章节42px、首屏圆角30px。本规范分别收敛为40/24/16/40/32px；正文15px保留，行高收敛28px。表头、卡片、首尾渐变的颜色保留。**这是规范化复用，不是逐像素复刻。**

### 4.3 玻璃落点（light）

| 位置 | 玻璃 | 说明 |
|---|---|---|
| 跨浅蓝首屏与页面底色交界的浮动章节导航条 | ✅ 仅此一处 | 用 `--glass-fill` + `--glass-stroke-soft` + shadow-s；条内胶囊仍是白底蓝字 |
| 结论直接排版、长文正文卡片、表格、折叠区、票据、收尾、提示条、六态控件 | ❌ | 保持不透明白浮，长文阅读优先 |

- **本条为 §2.4 明确列出的唯一例外，按决定保留玻璃，不改成实白导航条。** 浅底与页面底亮度接近，模糊收益有限；保留理由是让首屏到正文有一道可辨识的层次边界，而不是追求折射效果。
- 白高光描边在近白底不可见，必须换 `--glass-stroke-soft`；可用极轻的 shadow-s 帮助分层，不加第二层玻璃。
- 玻璃内文字一律 `--ink`；条内胶囊自带白底，控件六态不受玻璃影响。
- 不用 `filter:blur()` 替代 `backdrop-filter`（会把文字一起糊掉），也不给面板整体加 `opacity<1`；打印与不支持模糊时回退到 `--glass-fallback` / `--glass-print`。

## 5. 交互六态与可用性底线（两套共用）

| 状态 | 统一要求 | 落点 |
|---|---|---|
| 默认 | 文本按钮/链接使用 link，轮廓及文案可识别 | 两套 |
| 悬停 | 浅蓝底或明确下划线；不靠阴影单一提示 | 按钮：deep 用 `--ink`、light 用 `--tint`；锚点与折叠：两套均 `--tint` |
| 按下 | **必须比悬停更深**，保持布局不跳动 | 按钮：deep `--ink-pressed:#082247`、light `--tint-pressed:#c6dcfa`；锚点与折叠：两套均 `--tint-pressed` |
| 禁用 | 原生 `disabled`；明确“暂不可用”，不能只有透明度变化 | 两套 |
| 加载 | `aria-disabled="true"` + `aria-busy="true"` + “处理中…” 文字 + `role="status" aria-live="polite"`，**不用原生 `disabled`** | 两套 |
| 错误 | danger-bg + danger 文字 + 明确错误说明，关联 `aria-describedby`；不能只变红 | 两套 |

- **适用范围**：锚点类控件只需默认 / 悬停 / 按下 / 焦点四态；禁用、加载、错误仅按钮适用。静态段落/卡片不硬造六态。模板陈列状态只作视觉示例，不暗示真实接口已实现。锚点与折叠 `summary` 必须同时有悬停与按下反馈，按下用 `--tint-pressed`，不得只有悬停。
- 焦点独立于六态：`focus-visible` 3px link 色外框、偏移3px；深色区用清晰的浅色外框。
- 正文、小字、标签至少 4.5:1；大字至少 3:1。控件必要轮廓/状态与邻接底至少3:1；装饰细线不冒充可用轮廓。
- 所有可点区域至少44×44px；图标按钮有可读名称；键盘能走完导航、折叠和主流程。
- **空态组件 `.empty`**：结构为「一句原因 + 一句边界 + 一个下一动作」，虚线 line 描边、12/24 圆角、surface 底，**起始对齐（`text-align:start`）**；**静态空态不加 live region**，只有异步返回、确实需要被播报时才用 `role="status"`，避免页面加载时整段朗读；明确写“暂无内容 / 无登记≠无产出”，未知和 0 不能混写；不靠颜色传达。示例：`<div class="empty"><h3>暂无记录</h3><p>本周期尚未登记事项；无登记不等于无产出。</p><a class="button" href="#…">查看说明</a></div>`。
- **减少动效下的加载**：`prefers-reduced-motion` 下 spinner 停止旋转且隐藏静态圆环，只保留“处理中…”文字与 `aria-live`，不让它看起来像禁用态。
- **加载不是禁用**：加载态用 `aria-disabled="true"` + `aria-busy="true"` 保持可聚焦，配合脚本拦截重复提交；原生 `disabled` 会把按钮移出 Tab 序列，busy 变化无法被聚焦感知。原生 `disabled` 只用于真正的禁用态。
- 支持 `prefers-reduced-motion`，默认不做循环光晕动画；打印移除阴影、保留正文与来源。
- **玻璃层不参与六态**：状态控件一律不透明底，状态变化不得只靠透明度；玻璃不能削弱焦点外框。
- **玻璃对比度按合成底测量**：先算渐变最亮端 + 光晕 + 保护层，再叠加玻璃白底得到实际底色，不用原色对比度替代；deep `.55` 底 ink 最差 5.64:1、`.72` 底 8.30:1，light `.55` 底 ink ≥4.5:1，玻璃内禁用 muted / link 小字。
- 玻璃面板出现时仍须满足 44px 触区、3px 焦点外框与键盘路径；`overflow:hidden`、负外边距不得裁掉焦点描边。
- 长标题、长链接、超大数字不得截断关键含义；`overflow-wrap:anywhere` 为默认。

## 6. 最小验收与调用

1. 确认所选套装标记、首屏/字色/结论/收尾一致，无混搭。
2. 检查颜色变量、字阶成组、间距梯度、三档圆角/阴影；无外部字体、脚本、图片依赖；无未使用 token、无个人路径或外部链接。
3. 检查正文与标签色对、深色渐变最亮处、焦点和44px触区；不能用原色对比度替代半透明合成后的检查。
4. 检查宽屏、1024px 中间宽度、390px/360px 窄屏、200% 缩放、长文案、空态、表格滚动及键盘；不凭静态检查宣称真实交互已验收。**200% 缩放按整页缩放验收**（等效视口宽度减半，如 1280px 屏对应 640px 视口）；模板使用 px 字阶，不以浏览器“仅放大字体”作为通过标准。窄屏须用设备指标覆写或真实设备，桌面窗口直接设 360/390 会被钳制为约 500px。
5. 渲染后看首屏、中部、尾部，确认无截断和横向溢出；最后交付单文件HTML。未完成的验证必须如实说明。
6. 检查玻璃只在 3.3 / 4.3 允许的位置、只有一层、内部文字全为 `--ink`，并已按合成底测过对比度；deep 模糊层 ≤3、light ≤1。
7. 检查 `@supports` 降级、打印回退、`backdrop-filter` 与 `-webkit-backdrop-filter` 成对；在目标浏览器实际看一次“无模糊”版本，不能只看支持模糊的效果。
8. 检查 hover 与 active 不同色（按钮、锚点、折叠分别核对）、静态空态不冒充 live region、加载态可聚焦且带 `aria-live`、减少动效下加载仍有文字、方向属性为逻辑属性、玻璃在强制色彩模式关闭模糊。

**深蓝白调用句**：按 blue-white-design 的 deep 套装生成；首尾深蓝渐变与受保护的反白文字，中间白浮卡片，按共享 token 收敛排版。

**浅蓝白调用句**：按 blue-white-design 的 light 套装生成；浅蓝首屏、墨蓝正文、白至浅蓝卡片、浅蓝收尾，保留跨首屏的玻璃导航条，严禁套入深色首尾和白字玻璃卡。

**玻璃增强调用句**：按 deep 套装生成，并按 v3.1 在收尾节点容器与跨首屏的浮动导航条使用玻璃层（共 3 个模糊层）；结论主块仍反白，正文、表格与按钮不玻璃化。
